# カコモと学ぶ 決算チャレンジ — ハブページ

加古川市 令和7年度決算の11款シリーズへのリンク集です。

## 構成

- `index.html` — 本体(単一HTMLファイル、外部ゲームロジックなし)
- `manifest.json` — PWAマニフェスト
- `sw.js` — オフラインキャッシュ用の最小限のService Worker
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — アイコン(各款と共通)
- `og-image.png` — SNSシェア用画像(ハブページ専用)

## デザインについて

款ボタンは「押せる棒グラフ」方式です。バーの長さは決算総額に比例し、バーの中身は3色で構成を表します。

- 金色: 法定givの事業(市の裁量では動かせない金額)
- 水色: 裁量事業(市の判断で増減できる金額)
- 灰色: 事業カード外(決算総額のうち、個別の「事業」として評価・カード化されていない金額。多くは職員人件費等と推測される)

バーの下に、3区分それぞれの実額とパーセントを表示しています。この内訳は各款のindex.htmlに埋め込まれたDATA(main21の決算額合計とmandatoryタグ)から金額ベースで再集計したもので、事業数ベースの「法定◯/裁量◯」とは分子・分母が異なります。

## 進捗表示について

各款のindex.htmlは、localStorageキー`kessan_challenge_<款名>_v1`に②本編シミュレーション(事業ごとの増額/維持/減額/廃止の判断)の進捗(`{judged: {...}, running: 影響額}`)を保存しています。11款すべてが同じドメイン(chinjouojisan.github.io)配下にあり、オリジンが共有されているため、ハブページのJSから直接`localStorage.getItem(...)`で各款の進捗を読み取り、バーの下に「挑戦中 ○/○件」「判断済み ○/○件」のバッジを表示しています。

注意点:
- 保存されているのは②本編シミュレーションの進捗のみで、①入口クイズの正誤は保存されていません(クイズは訪問のたびにリセットされます)。ハブページの進捗表示もシミュレーション側のみが対象です
- ユーザーが実際にその端末・ブラウザでその款のページを開いて操作していないと、localStorageにデータが存在せずバッジは表示されません(未プレイの款は何も表示されない仕様です)

## 今回は実装しなかったこと(今後の課題)

- **(b)性質別(人件費・委託費・事業費等)の「動かせない/動かせるお金」チャート**は未実装です。決算資料の「節」データから機械集計は可能ですが、`歳出_節明細(実績)`シートに既知の誤りがあり、公債費の元金(約83億円)が丸ごと抜け落ちる欠陥を確認しています。実装する際は、公債費の元金(8,264,569,797円、`kessan_challenge_kosai_v1`のカードから取得済み)を手動で補正して使う想定です
- 款ごとの一言トリビアは、分量を見てから追加するかどうか判断する方針で、現版のボタンには含めていません

## オフライン対応(Service Worker)について

`sw.js`はindex.html・manifest.json・アイコン一式をキャッシュし、オフラインでも表示できるようにしています。**このハブページはまだ内容を頻繁に更新する段階なので、更新のたびに`sw.js`内の`CACHE_NAME`(例: `kessan-challenge-hub-v1` → `v2`)をインクリメントしてください。** バージョンを上げないと、一度訪問したユーザーのブラウザには古いキャッシュが残り続け、更新が反映されません。
